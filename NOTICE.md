# Erkenningen

QuitChat (AGPL-3.0) bevat geen code van onderstaande projecten, maar
downloadt en gebruikt ze tijdens de installatie. Hun eigen licenties blijven
voor hun code gelden.

| Project | Wat het doet in QuitChat | Licentie |
| --- | --- | --- |
| [muxbee](https://github.com/tobocop2/muxbee) door tobocop2 | Zet Synapse, Element en de bridges op | MIT |
| [mautrix-signal](https://github.com/mautrix/signal), [mautrix-whatsapp](https://github.com/mautrix/whatsapp) door Tulir Asokan | De bridges naar Signal en WhatsApp | AGPL-3.0 |
| [Synapse](https://github.com/element-hq/synapse) | De Matrix-server | AGPL-3.0 |
| [Element Web](https://github.com/element-hq/element-web) | Chat-scherm in de browser | AGPL-3.0 |
| [PostgreSQL](https://www.postgresql.org) | Database | PostgreSQL License |
| [Tailscale](https://tailscale.com) | Toegang vanaf je telefoon | BSD-3-Clause (client) |
| [Docker](https://www.docker.com) | Draait alle onderdelen | Apache-2.0 |

Muxbee is in juni 2026 door de maker gearchiveerd. Wordt er later code van
muxbee in QuitChat opgenomen of aangepast (een fork), dan blijft de
MIT-licentie van muxbee met de naam van de maker bij die code staan.

Dank aan iedereen die deze projecten bouwt en onderhoudt.
